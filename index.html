01 / El sistema

Un cambio. Un push. Una web en producción.

Este proyecto convierte una actualización del código en una publicación verificable. GitHub Actions comprueba que exista la página y la despliega con GitHub Pages.

Paso 01

Escribe

Actualiza el contenido del sitio en el repositorio.

Paso 02

Envía

Guarda el cambio en Git y súbelo a la rama principal.

Paso 03

Publica

Actions valida y despliega la nueva versión del sitio.
